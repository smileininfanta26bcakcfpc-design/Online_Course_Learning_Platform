Project Overview
WiziQ is a modern online learning course platform designed to provide students with a simple and engaging way to explore courses, enroll in lessons, learn through video content, complete quizzes, and track their learning progress.
The UI is designed with a purple-based educational theme, creating a consistent visual experience across all screens.
Project Objective
The main objective of this project is to design a user-friendly online learning platform that allows students to:
Explore available courses
View detailed course information
Enroll in courses
Watch learning content
Take quizzes
Track course progress
View enrolled courses and learning statistics
